# J.A.R.V.I.S. 2.0 — conserto completo

## O que estava quebrado

| Problema | Causa | Conserto |
|---|---|---|
| **Não respondia** | O cérebro era uma fila que só andava com o Muse aberto e lendo os pedidos. Na nuvem ninguém lia, então ele ficava "pensando..." pra sempre. | Agora o Jarvis pensa sozinho com o Groq (grátis). Se o Muse estiver conectado, quem responde é ele. |
| **Não ouvia** | A transcrição dependia da chave `GROQ_API_KEY`, que não estava configurada. O erro era escondido e a tela continuava mostrando "ouvindo...". | Agora ele ouve pelo próprio Chrome/Edge, sem precisar de chave. O Whisper do Groq fica como reserva, e os erros aparecem na tela. |
| **Voz Faber muda** | O Piper foi enviado sem as bibliotecas que ele precisa pra rodar. | Incluí as bibliotecas pra Linux (Render) e a versão completa pra Windows. |
| Gravava só 5 s | Cortava a sua frase no meio. | Agora ele espera você terminar de falar. |

## 1. Pegue a chave grátis do Groq (2 minutos)
1. Entre em **https://console.groq.com/keys** e faça login com o Google.
2. Clique em **Create API Key** e copie a chave (começa com `gsk_`).

## 2. Na nuvem (Render)
1. No GitHub do Jarvis, troque os arquivos pelos desta pasta: `server.js`, `package.json`, a pasta `public` e a pasta `system`.
   - O arquivo `pt_BR-faber-medium.onnx` (61 MB) já está lá, então não precisa reenviar. O site do GitHub não aceita arquivos acima de 25 MB.
   - Os outros arquivos novos da pasta `system/piper` (`lib*.so*`, `espeak-ng-data`) **precisam** subir.
2. No Render, entre no seu serviço e vá em **Environment → Add Environment Variable**:
   - `GROQ_API_KEY` = sua chave
   - `NOME_DONO` = como ele deve te chamar (ex.: `senhor`, `Alberto`)
   - `CIDADE_PADRAO` = sua cidade (ex.: `Maceió`)
3. Clique em **Manual Deploy → Deploy latest commit**.
4. Abra `https://jarvis-1-0mxx.onrender.com` no **Chrome** ou no **Edge** e toque na tela.

> O plano grátis do Render "dorme" depois de 15 min sem uso. O primeiro acesso pode levar uns 50 s pra acordar.

## 3. No computador (Windows)
1. Instale o **Node.js LTS**: https://nodejs.org
2. Dê dois cliques em **`INICIAR-JARVIS.bat`**.
   - Na primeira vez, ele instala tudo e abre o arquivo `.env`. Cole a chave depois de `GROQ_API_KEY=`, salve e feche.
3. O navegador abre em `http://localhost:3000`.

No PC, o Jarvis também **abre programas e sites** e mostra o uso de CPU e memória reais.

## 4. Usar no celular (app PWA)
1. Abra o endereço da nuvem no **Chrome do Android**.
2. Toque em **⬇ INSTALAR NO CELULAR** (ou no menu ⋮ → "Instalar app"/"Adicionar à tela inicial").
   - No iPhone: botão **Compartilhar** → **Adicionar à Tela de Início**.
3. Pronto: fica com ícone igual a um app e abre rápido mesmo na rua.

Assim ele funciona em qualquer lugar: voz, respostas, dados em tempo real e o modo visão. Os comandos que mexem no computador (abrir programa, volume) só funcionam no PC.

## 5. As interfaces
Troque pelo botão de camadas, pela tecla `I` ou falando *"muda pra holograma"*, *"modo tempestade"* ou *"volta pra esfera"*. A escolha fica salva.
- **Núcleo** (padrão): o reator de arco (estilo Homem de Ferro) com anéis de HUD girando, anel de onda sonora que dança com a voz e leituras de dados. É a interface-assinatura.
- **Holograma**: busto de linhas ciano com rosto laranja que ondula quando ele fala, veias de energia no pescoço, anéis de HUD girando, montanhas de partículas no fundo e montagem a partir de uma esfera de luz.
- **Tempestade**: busto masculino em neon roxo e dourado, com olhos que acendem ao falar, núcleo de energia no peito, fumaça e raios.
- **Esfera**: rede neural 3D azul que gira e cria espinhos com a voz.
- **Visão** (botão da câmera ou tecla `C`, ou diga *"ativa o modo visão"*): abre a câmera do aparelho com um HUD de scanner por cima — retículo, linhas de varredura e anéis. É só efeito visual: **não reconhece pessoas nem mostra dados de ninguém**.

As legendas aparecem palavra por palavra. O painel do canto direito mostra o clima da sua cidade, o dólar, o bitcoin e os timers ativos.

## Voz premium (parecida com a dos vídeos)
A voz grátis é a **Faber** (Piper) — funciona, mas é mais robótica. Para a voz grave e natural estilo dos vídeos, use o **ElevenLabs** (tem plano grátis):
1. Crie conta em https://elevenlabs.io e copie sua **API Key** (Profile → API Key).
2. No PC: coloque no `.env` em `ELEVENLABS_API_KEY=`. Na nuvem: adicione a variável `ELEVENLABS_API_KEY` no Render.
3. (Opcional) Troque a voz em `ELEVENLABS_VOICE_ID` pelo ID de outra voz do ElevenLabs. A padrão é uma voz masculina grave.

Quando estiver ativa, o painel mostra **VOZ: PREMIUM**. Se faltar, ele volta sozinho para a Faber e, se nem ela, para a voz do navegador.

> Não dá para clonar exatamente a voz de um vídeo (isso precisaria do consentimento do dono da voz). Essas reels usam vozes de IA prontas; o ElevenLabs chega bem perto do mesmo tom.

**Atalhos:** `Espaço` microfone · `S` sentinela · `C` câmera · `T` digitar · `M` mudo · `I` interface.

### Casa inteligente (ligar luz, TV, tomada…)
O Jarvis não fala direto com a lâmpada — ele dispara um **link (webhook)** que o seu app de casa inteligente oferece. Passo a passo:
1. Toque no botão da **casinha** (abre a tela "Casa") ou vá em `/casa.html`.
2. No seu app (Smart Life/Tuya, SmartThings, Alexa, IFTTT, Home Assistant…) crie uma cena/automação **"ligar"** e outra **"desligar"** para cada aparelho e copie o link de cada uma.
3. Na tela "Casa", adicione o aparelho com um **nome** (como você vai falar, ex.: "luz da sala"), cole os links de **ligar** e **desligar**, e toque em **Testar** e **Salvar**.
4. Pronto: fale *"liga a luz da sala"*, *"desliga a TV"*, *"liga tudo"*.

Se usa **Home Assistant**: na tela "Casa" preencha o endereço e o token, e no aparelho escolha o tipo "Home Assistant" com a entidade (ex.: `light.sala`).

> **Nuvem (Render):** o que você salva na tela "Casa" se perde quando o serviço reinicia. Para não perder, use o botão **"Copiar para o Render"** e cole o texto na variável `CASA_JSON` (Render → Environment). No PC fica salvo na pasta `dados`.
> A nuvem só alcança aparelhos com link **público** (IFTTT, Tuya, Home Assistant exposto/Nabu Casa). Aparelhos só na sua rede local funcionam com o Jarvis rodando no PC de casa.

### O que ele NÃO faz (de propósito)
Reconhecer pessoas na rua pela câmera, mostrar nome/idade/endereço de estranhos ou marcar alguém como "ameaça"; "hackear" aparelhos; invadir sistemas de empresas. Esses vídeos virais são encenação — nenhum app faz isso de verdade. O modo visão é só um efeito de scanner.

## 7. Usar o Muse como cérebro (opcional)
O Jarvis é compatível com o Muse. No Muse, mande esta instrução (troque o endereço pelo seu, se for outro):

> Monitore `https://jarvis-1-0mxx.onrender.com/api/muse-brain/queue` a cada 2 segundos. Para cada pedido da lista, responda como J.A.R.V.I.S. — curto, em português do Brasil, me chamando de senhor — enviando um POST para `https://jarvis-1-0mxx.onrender.com/api/muse-brain/respond` com o JSON `{"id": "<id do pedido>", "response": "<sua resposta>"}`. Para abrir um site, acrescente `"control": {"tipo": "abrir_site", "url": "https://..."}`; para trocar a interface, `"control": {"tipo": "interface", "modo": "holograma"}`.

Enquanto o Muse estiver lendo a fila, o painel mostra **CÉREBRO: MUSE**. Se ele parar de responder ou demorar mais de 25 s, o Groq assume na hora e o Jarvis nunca mais trava — foi exatamente esse travamento que quebrava o seu Jarvis antigo.

## Deixar o cérebro mais inteligente
Por padrão ele pensa com o Groq (grátis e rápido). Para ficar mais esperto:
- **Modelo mais forte no Groq:** adicione a variável `GROQ_MODELO` = `meta-llama/llama-4-maverick-17b-128e-instruct`.
- **Usar o Gemini** (tem plano grátis e é bem inteligente): crie a chave em aistudio.google.com/apikey, adicione `GEMINI_API_KEY` e `CEREBRO_PRINCIPAL=gemini`.

## Problemas comuns
- **"Falha nos circuitos" / "chave recusada":** a `GROQ_API_KEY` está errada ou colada com espaço. Gere outra em console.groq.com/keys, apague a variável no Render e cadastre de novo (sem espaços), depois **Manual Deploy**. A tela mostra o motivo técnico embaixo da resposta.
- **Deu certo no teste mas o primeiro acesso falha:** no plano grátis o Render "dorme". Espere ~50s, recarregue e tente de novo.
- **"Permita o uso do microfone"**: toque no cadeado ao lado do endereço e libere o **Microfone**.
- **Não ouve no Brave, Opera ou Firefox**: esses navegadores não têm reconhecimento de voz. O Jarvis troca sozinho para o Whisper, que precisa da `GROQ_API_KEY`. Use o Chrome ou o Edge.
- **"Meu cérebro está desligado"**: falta configurar a `GROQ_API_KEY`.
- **Conferir o estado**: abra `/api/health` no endereço do Jarvis.

const fila = new Map();       // id -> pedido
const respostas = new Map();  // id -> resposta
let ultimaLeituraMuse = 0;
const museOnline = () => process.env.MUSE_MODO !== 'desligado' && Date.now() - ultimaLeituraMuse < 30000;
const novoId = () => Math.random().toString(36).slice(2, 10);

function enfileirar(text, language) {
  const id = novoId();
  fila.set(id, { id, text, language: language || 'BR', ts: Date.now(), status: 'pending' });
  // limpa pedidos velhos (mais de 10 min)
  for (const [k, v] of fila) if (Date.now() - v.ts > 600000) fila.delete(k);
  return id;
}

async function esperarMuse(id, ms) {
  const ini = Date.now();
  while (Date.now() - ini < ms) {
    if (respostas.has(id)) { const r = respostas.get(id); respostas.delete(id); return r; }
    await new Promise(r => setTimeout(r, 400));
  }
  fila.delete(id);
  return null;
}

app.get('/api/muse-brain/queue', (req, res) => {
  ultimaLeituraMuse = Date.now();
  res.json([...fila.values()].filter(x => x.status === 'pending'));

app.post('/api/muse-brain/respond', (req, res) => {
  const { id, response, audio_url, control } = req.body || {};

  ultimaLeituraMuse = Date.now();
  respostas.set(id, { response, audio_url, control });
  fila.delete(id);
  res.json({ ok: true });
});

function lerJSON(txt) {
  if (!txt) return null;
  try { return JSON.parse(txt); } catch {}
  const m = txt.match(/\{[\s\S]*\}/);
  if (m) try { return JSON.parse(m[0]); } catch {}
  return { fala: txt, acao: null };
}

function montarMensagens(texto, historico) {
  const hist = (Array.isArray(historico) ? historico : []).slice(-12)
    .filter(h => h && h.content && (h.role === 'user' || h.role === 'assistant'))
    .map(h => ({ role: h.role, content: String(h.content).slice(0, 1500) }));
  return [{ role: 'system', content: promptSistema() }, ...hist, { role: 'user', content: texto }];
}

async function chatEstiloOpenAI(url, chave, modelo, msgs) {
  const r = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${(chave || '').trim()}` },
    // sem response_format: alguns modelos rejeitam e derrubam tudo. lerJSON extrai o JSON do texto.
    body: JSON.stringify({ model: modelo, messages: msgs, temperature: 0.7, max_tokens: 500 }),
    signal: AbortSignal.timeout(30000)
  });
  const d = await r.json().catch(() => ({}));
  if (!r.ok) throw new Error(d.error?.message || `HTTP ${r.status}`);
  return lerJSON(d.choices?.[0]?.message?.content);
}

// Groq com vários modelos: se um estiver fora do ar/descontinuado, tenta o próximo
const GROQ_MODELOS = (process.env.GROQ_MODELO ? [process.env.GROQ_MODELO] : [])
  .concat(['llama-3.3-70b-versatile', 'meta-llama/llama-4-maverick-17b-128e-instruct', 'llama-3.1-8b-instant', 'gemma2-9b-it']);
let groqErro = '';
async function chatGroq(msgs) {
  let ultimo = '';
  for (const modelo of [...new Set(GROQ_MODELOS)]) {
    try { return await chatEstiloOpenAI('https://api.groq.com/openai/v1/chat/completions', process.env.GROQ_API_KEY, modelo, msgs); }
    catch (e) {
      ultimo = `${modelo}: ${e.message}`;
      log('⚠️ groq', ultimo);
      // chave inválida/sem crédito: não adianta tentar outro modelo
      if (/401|invalid|api key|unauthor/i.test(e.message)) break;
    }
  }
  groqErro = ultimo;
  throw new Error(ultimo || 'groq falhou');
}

async function chatGemini(chave, modelo, msgs) {
  const sys = msgs[0].content;
  const contents = msgs.slice(1).map(m => ({ role: m.role === 'assistant' ? 'model' : 'user', parts: [{ text: m.content }] }));
  const r = await fetch(`https://generativelanguage.googleapis.com/v1beta/models/${modelo}:generateContent?key=${chave}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      systemInstruction: { parts: [{ text: sys }] },
      contents,
      generationConfig: { temperature: 0.7, maxOutputTokens: 400, responseMimeType: 'application/json' }
    }),
    signal: AbortSignal.timeout(30000)
  });
  const d = await r.json().catch(() => ({}));
  if (!r.ok) throw new Error(d.error?.message || `HTTP ${r.status}`);
  return lerJSON(d.candidates?.[0]?.content?.parts?.map(p => p.text).join(''));
}

// Claude (Anthropic) — cérebro forte, porém PAGO (sem plano grátis)
async function chatClaude(chave, modelo, msgs) {
  const sys = msgs[0].content;
  let hist = msgs.slice(1).map(m => ({ role: m.role === 'assistant' ? 'assistant' : 'user', content: String(m.content) }));
  while (hist.length && hist[0].role !== 'user') hist.shift(); // Anthropic exige começar com 'user'
  const r = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'x-api-key': (chave || '').trim(), 'anthropic-version': '2023-06-01' },
    body: JSON.stringify({ model: modelo, max_tokens: 500, temperature: 0.7, system: sys, messages: hist }),
    signal: AbortSignal.timeout(30000)
  });
  const d = await r.json().catch(() => ({}));
  if (!r.ok) throw new Error(d.error?.message || `HTTP ${r.status}`);
  return lerJSON((d.content || []).map(c => c.text || '').join(''));
}

function cerebrosDisponiveis() {
  const lista = [];
  if (process.env.GROQ_API_KEY) lista.push({ nome: 'groq', fn: chatGroq });
  if (process.env.GEMINI_API_KEY) lista.push({ nome: 'gemini', fn: m => chatGemini(process.env.GEMINI_API_KEY, process.env.GEMINI_MODELO || 'gemini-2.5-flash', m) });
  if (process.env.ANTHROPIC_API_KEY) lista.push({ nome: 'claude', fn: m => chatClaude(process.env.ANTHROPIC_API_KEY, process.env.CLAUDE_MODELO || 'claude-3-5-sonnet-latest', m) });
  if (process.env.OPENAI_API_KEY) lista.push({ nome: 'openai', fn: m => chatEstiloOpenAI(process.env.OPENAI_URL || 'https://api.openai.com/v1/chat/completions', process.env.OPENAI_API_KEY, process.env.OPENAI_MODELO || 'gpt-4o-mini', m) });

  return lista;
}

// Respostas instantâneas que funcionam até sem nenhuma chave
function respostaRapida(texto) {
  const t = texto.toLowerCase().normalize('NFD').replace(/[̀-ͯ]/g, '');
  const tz = { timeZone: 'America/Sao_Paulo' };
  if (/\b(que horas|horas sao|hora agora)\b/.test(t))
    return { fala: `São ${new Date().toLocaleTimeString('pt-BR', { ...tz, hour: '2-digit', minute: '2-digit' })}, ${NOME_DONO}.`, acao: null };
  const modo = /\b(nucleo|núcleo|reator|reactor|core|coração|coracao)\b/.test(t) ? 'nucleo' : /\b(visao|visão|camera|câmera|scanner|olhar|ver)\b/.test(t) ? 'camera' : /\b(holograma|hologram)\b/.test(t) ? 'holograma' : /\b(tempestade|violeta|roxa|roxo|raio|raios)\b/.test(t) ? 'tempestade' : /\b(esfera|bola|rede neural)\b/.test(t) ? 'esfera' : null;
  if (modo && /\b(muda|mude|mudar|troca|troque|trocar|modo|interface|ativa|ative|ativar|liga|ligar|abre|abrir|coloca|coloque|vira|virar)\b/.test(t))
    return { fala: modo === 'camera' ? `Ativando o modo visão, ${NOME_DONO}.` : `Alterando a interface para ${modo}, ${NOME_DONO}.`, acao: { tipo: 'interface', modo } };
  if (/\b(que dia|data de hoje|dia e hoje|dia hoje)\b/.test(t))
    return { fala: `Hoje é ${new Date().toLocaleDateString('pt-BR', { ...tz, weekday: 'long', day: 'numeric', month: 'long', year: 'numeric' })}.`, acao: null };
  // visão de tela
  if (/\b(para|pare|parar|chega|cancela)\b/.test(t) && /\b(vigi|acompanh|observ|olhando|monitor)\w*\s+(a\s+)?(minha\s+)?tela/.test(t))
    return { fala: `Parei de acompanhar sua tela, ${NOME_DONO}.`, acao: { tipo: 'tela', sub: 'parar' } };
  if (/\b(vigi|acompanh|observ|monitor|fica de olho|me avis)\w*/.test(t) && /\btela\b/.test(t))
    return { fala: `A partir de agora vou acompanhar a sua tela, ${NOME_DONO}.`, acao: { tipo: 'tela', sub: 'vigiar' } };
  if (/\btela\b/.test(t) && /\b(o que|que que|ve|vê|vendo|olha|olhe|descrev|mostra|tem na|analis|aparece)\w*/.test(t))
    return { fala: `Deixe-me ver, ${NOME_DONO}.`, acao: { tipo: 'tela', sub: 'descrever', pergunta: '' } };
  return null;
}

// Loop de ferramentas: a IA pede um dado real, o servidor busca e devolve
async function pensarComFerramentas(cerebro, msgs) {
  let conversa = msgs;
  const usadas = [];
  for (let rodada = 0; rodada < 3; rodada++) {
    const r = await cerebro.fn(conversa);
    const f = r?.ferramenta;
    if (f && typeof f === 'object' && f.nome && rodada < 2) {
      const resultado = await executarFerramenta(f);
      log('🔧', f.nome, JSON.stringify(resultado).slice(0, 160));
      usadas.push(f.nome);
      conversa = [...conversa,
        { role: 'assistant', content: JSON.stringify({ fala: r.fala || '', ferramenta: f }) },
        { role: 'user', content: `RESULTADO DA FERRAMENTA "${f.nome}": ${JSON.stringify(resultado).slice(0, 3500)}\nAgora responda ao ${NOME_DONO} usando esses dados, em JSON {"fala": "...", "acao": null}. Não chame ferramenta de novo.` }];
      continue;
    }
    return { ...r, ferramentas: usadas };
  }
  return { fala: '', ferramentas: usadas };
}

function falaCasa(r, cmd) {
  const dono = NOME_DONO;
  const verbo = (cmd.acao === 'desligar') ? 'Desliguei' : 'Liguei';
  if (r.motivo === 'nenhum_dispositivo')
    return { fala: `${dono[0].toUpperCase() + dono.slice(1)}, ainda não há aparelhos cadastrados. Abra a tela "Casa" e adicione os seus.`, acao: null };
  if (r.motivo === 'nao_encontrado')
    return { fala: `Não encontrei "${cmd.alvo}" na sua casa, ${dono}.`, acao: null };
  if (!r.ok)
    return { fala: `Não consegui ${cmd.acao === 'desligar' ? 'desligar' : 'ligar'} agora, ${dono}. ${r.falhas?.[0]?.erro || ''}`.trim(), acao: null };
  const alvoTxt = /tudo|geral/.test((cmd.alvo || '').toLowerCase()) ? 'tudo' : (r.feitos.length > 1 ? r.feitos.join(', ') : r.feitos[0]);
  const resto = r.falhas?.length ? ` Só não consegui ${r.falhas.map(f => f.nome).join(', ')}.` : '';
  return { fala: `${verbo} ${alvoTxt}, ${dono}.${resto}`, acao: null };
}

app.post('/api/chat', async (req, res) => {
  const { text, history } = req.body || {};
  const texto = String(text || '').trim();
  if (!texto) return res.status(400).json({ error: 'texto vazio' });
  log('🗣️ ', texto);

  // 0) comandos instantâneos (hora, data, trocar interface)
  const instantanea = respostaRapida(texto);
  if (instantanea) return res.json({ ...instantanea, cerebro: 'local' });

  // 0b) casa inteligente: liga/desliga aparelhos (executado no servidor)
  const cmdCasa = casa.comandoDoTexto(texto);
  if (cmdCasa) {
    const r = await casa.acionar(cmdCasa.acao, cmdCasa.alvo);
    return res.json({ ...falaCasa(r, cmdCasa), cerebro: 'casa' });
  }
  // avisa quando pede luz/tv mas nada foi configurado ainda
  if (/\b(liga|ligar|ligue|acende|desliga|desligar|apaga)\b/i.test(texto) && /\b(luz|lâmpada|lampada|tv|televis|tomada|ar.?condicionado|ventilador|abajur)\b/i.test(texto) && !casa.listar().length)
    return res.json({ fala: `${NOME_DONO[0].toUpperCase() + NOME_DONO.slice(1)}, ainda não cadastrei seus aparelhos. Abra a tela "Casa" (botão da casinha) e adicione a luz, a TV e o que mais quiser controlar.`, acao: null, cerebro: 'casa' });

  // 1) Muse, se estiver conectado lendo a fila
  if (museOnline()) {
    const r = await esperarMuse(enfileirar(texto), Number(process.env.MUSE_ESPERA_MS || 25000));
    if (r && r.response) {
      log('🧠 muse:', r.response);
      return res.json({ fala: r.response, acao: r.control || null, audio_url: r.audio_url || null, cerebro: 'muse' });
    }
    log('⚠️  Muse não respondeu a tempo, usando IA reserva');
  }

  const rapida = respostaRapida(texto);
  const cerebros = cerebrosDisponiveis();
  if (!cerebros.length) {
    if (rapida) return res.json({ ...rapida, cerebro: 'local' });
    return res.json({
      fala: `${NOME_DONO[0].toUpperCase() + NOME_DONO.slice(1)}, meu cérebro está desligado. Configure a chave GROQ_API_KEY para eu poder pensar.`,
      acao: null, cerebro: 'nenhum', erro: 'sem_chave'
    });
  }

  // 2) IAs reserva, em ordem, até uma funcionar
  const msgs = montarMensagens(texto, history);
  let ultimoErro = '';
  for (const c of cerebros) {
    try {
      const r = await pensarComFerramentas(c, msgs);
      let fala = String(r?.fala || r?.resposta || r?.response || '').trim();
      // ação de casa vinda do cérebro: executa no servidor
      if (r.acao && r.acao.tipo === 'casa') {
        const rc = await casa.acionar(r.acao.acao, r.acao.alvo || r.acao.aparelho || 'tudo');
        const fc = falaCasa(rc, { acao: r.acao.acao, alvo: r.acao.alvo });
        return res.json({ ...fc, cerebro: c.nome });
      }
      if (!fala) throw new Error('resposta vazia');
      log(`🧠 ${c.nome}:`, fala, r.acao ? JSON.stringify(r.acao) : '');
      return res.json({ fala, acao: r.acao || null, cerebro: c.nome, ferramentas: r.ferramentas });
    } catch (e) {
      ultimoErro = `${c.nome}: ${e.message}`;
      log('❌', ultimoErro);
    }
  }
  if (rapida) return res.json({ ...rapida, cerebro: 'local' });
  const det = ultimoErro || groqErro || '';
  const chaveRuim = /401|invalid|api key|unauthor|no api key/i.test(det);
  const falaErro = chaveRuim
    ? `${NOME_DONO[0].toUpperCase() + NOME_DONO.slice(1)}, minha chave de acesso foi recusada. Confira a GROQ_API_KEY.`
    : `Desculpe, ${NOME_DONO}, meu cérebro não respondeu. Tente de novo em instantes.`;
  res.json({ fala: falaErro, acao: null, cerebro: 'erro', erro: chaveRuim ? 'chave_invalida' : 'falha', detalhe: det });
});

const PIPER_DIR = path.join(__dirname, 'system', process.platform === 'win32' ? 'piper-windows' : 'piper');
const PIPER_BIN = path.join(PIPER_DIR, process.platform === 'win32' ? 'piper.exe' : 'piper');
const VOZ = [path.join(PIPER_DIR, 'pt_BR-faber-medium.onnx'), path.join(__dirname, 'system', 'piper', 'pt_BR-faber-medium.onnx')].find(f => fs.existsSync(f));
const piperExiste = () => ['linux', 'win32'].includes(process.platform) && fs.existsSync(PIPER_BIN) && !!VOZ;

function limparParaFala(t) {
  return String(t).replace(/[*_#`>~]/g, '').replace(/https?:\/\/\S+/g, '').replace(/[\u{1F300}-\u{1FAFF}\u{2600}-\u{27BF}]/gu, '').trim().slice(0, 1200);
}

function falarPiper(texto) {
  return new Promise((resolve, reject) => {
    const saida = path.join(os.tmpdir(), `jarvis-${Date.now()}-${novoId()}.wav`);
    const args = ['--model', VOZ, '--output_file', saida, '--length_scale', process.env.VOZ_VELOCIDADE || '0.92', '--sentence_silence', '0.15'];
    const espeak = path.join(PIPER_DIR, 'espeak-ng-data');
    if (fs.existsSync(espeak)) args.push('--espeak_data', espeak);
    const env = { ...process.env, LD_LIBRARY_PATH: [PIPER_DIR, process.env.LD_LIBRARY_PATH].filter(Boolean).join(':'), DYLD_LIBRARY_PATH: PIPER_DIR };
    const p = spawn(PIPER_BIN, args, { env, cwd: PIPER_DIR });
    let stderr = '';
    p.stderr.on('data', d => stderr += d);
    p.on('error', reject);
    p.on('close', code => {
      if (code !== 0 || !fs.existsSync(saida)) return reject(new Error(`piper código ${code}: ${stderr.slice(-300)}`));
      const audio = fs.readFileSync(saida);
      fs.unlink(saida, () => {});
      resolve(audio);
    });
    p.stdin.write(texto);
    p.stdin.end();
  });
}

}

//  reconhecimento de voz, ex.: Firefox, Brave, Safari antigo)

const upload = multer({ dest: os.tmpdir(), limits: { fileSize: 15 * 1024 * 1024 } });

app.post('/api/transcribe', upload.single('audio'), async (req, res) => {
  const apagar = () => { if (req.file) fs.unlink(req.file.path, () => {}); };
  const chave = process.env.GROQ_API_KEY;
  if (!chave) { apagar(); return res.status(503).json({ error: 'sem_chave', mensagem: 'Configure GROQ_API_KEY para transcrever áudio.' }); }
  if (!req.file) return res.status(400).json({ error: 'sem_audio' });
  try {
    const tipo = req.file.mimetype || 'audio/webm';
    const ext = tipo.includes('mp4') ? 'mp4' : tipo.includes('ogg') ? 'ogg' : tipo.includes('wav') ? 'wav' : 'webm';
    const bytes = fs.readFileSync(req.file.path);
    const modelos = [...new Set([process.env.WHISPER_MODELO, 'whisper-large-v3-turbo', 'whisper-large-v3'].filter(Boolean))];
    let ultimo = '';
    for (const modelo of modelos) {
      const fd = new FormData();
      fd.append('file', new Blob([bytes], { type: tipo }), `audio.${ext}`);
      fd.append('model', modelo);
      fd.append('language', 'pt');
      fd.append('response_format', 'json');
      const r = await fetch('https://api.groq.com/openai/v1/audio/transcriptions', {
        method: 'POST', headers: { Authorization: `Bearer ${chave.trim()}` }, body: fd, signal: AbortSignal.timeout(30000)
      });
      const d = await r.json().catch(() => ({}));
      if (r.ok) { apagar(); return res.json({ text: (d.text || '').trim() }); }
      ultimo = d.error?.message || `HTTP ${r.status}`;
      log('⚠️ whisper', modelo, ultimo);
      if (/401|invalid|api key|unauthor/i.test(ultimo)) break;
    }
    apagar();
    return res.status(502).json({ error: 'groq_falhou', mensagem: ultimo });
  } catch (e) {
    apagar();
    res.status(500).json({ error: 'erro', mensagem: e.message });
  }
});

  const n = String(nome || '').toLowerCase().normalize('NFD').replace(/[̀-ͯ]/g, '').trim();

function abrirNoPC(alvo, ehApp) {
  const plat = process.platform;
  let cmd, args;
  if (plat === 'win32') { cmd = 'cmd'; args = ['/c', 'start', '""', alvo]; }
  else if (plat === 'darwin') { cmd = 'open'; args = ehApp && !/^[a-z]+:/i.test(alvo) ? ['-a', alvo] : [alvo]; }
  else { cmd = ehApp && !/^[a-z]+:/i.test(alvo) ? alvo : 'xdg-open'; args = cmd === alvo ? [] : [alvo]; }
  const p = spawn(cmd, args, { detached: true, stdio: 'ignore', windowsVerbatimArguments: plat === 'win32', shell: false });
  p.on('error', e => log('❌ abrir:', e.message));
  p.unref();
}

// volume, mídia e bloqueio de tela
function comandoSistema(cmd) {
  const plat = process.platform;
  const rodar = (bin, args) => { const p = spawn(bin, args, { detached: true, stdio: 'ignore', windowsHide: true }); p.on('error', e => log('❌ sistema:', e.message)); p.unref(); };
  if (plat === 'win32') {
    const teclas = { volume_mais: 175, volume_menos: 174, mudo: 173, play_pause: 179, proxima: 176, anterior: 177 };
    if (cmd === 'bloquear') { rodar('rundll32.exe', ['user32.dll,LockWorkStation']); return true; }
    if (teclas[cmd]) {
      const vezes = cmd.startsWith('volume_') && cmd !== 'mudo' ? 5 : 1;
      rodar('powershell', ['-NoProfile', '-WindowStyle', 'Hidden', '-Command', `$w=New-Object -ComObject WScript.Shell; 1..${vezes} | % { $w.SendKeys([char]${teclas[cmd]}) }`]);
      return true;
    }
  }
  if (plat === 'darwin') {
    const as = {
      volume_mais: 'set volume output volume ((output volume of (get volume settings)) + 10)',
      volume_menos: 'set volume output volume ((output volume of (get volume settings)) - 10)',
      mudo: 'set volume output muted (not (output muted of (get volume settings)))'
    };
    if (as[cmd]) { rodar('osascript', ['-e', as[cmd]]); return true; }
    if (cmd === 'bloquear') { rodar('pmset', ['displaysleepnow']); return true; }
  }
  return false;
}

const pegar = async (url, tipo = 'json') => {
  const r = await fetch(url, { headers: { 'User-Agent': 'JARVIS/2.0 (assistente pessoal)' }, signal: AbortSignal.timeout(9000) });
  if (!r.ok) throw new Error(`HTTP ${r.status}`);
  return tipo === 'json' ? r.json() : r.text();
};

// ── CLIMA ──────────────────────────────────────────────────────
const CODIGOS = {
  0: 'céu limpo', 1: 'predominantemente limpo', 2: 'parcialmente nublado', 3: 'nublado', 45: 'neblina', 48: 'neblina',
  51: 'garoa fraca', 53: 'garoa', 55: 'garoa forte', 61: 'chuva fraca', 63: 'chuva', 65: 'chuva forte',
  66: 'chuva congelante', 67: 'chuva congelante', 71: 'neve fraca', 73: 'neve', 75: 'neve forte',
  80: 'pancadas de chuva', 81: 'pancadas de chuva', 82: 'pancadas fortes de chuva', 95: 'trovoadas', 96: 'trovoadas com granizo', 99: 'trovoadas com granizo'
};
const cacheGeo = new Map();
export async function clima(cidade) {
  cidade = String(cidade || '').trim() || process.env.CIDADE_PADRAO || 'Maceió';
  let geo = cacheGeo.get(cidade.toLowerCase());
  if (!geo) {
    const g = await pegar(`https://geocoding-api.open-meteo.com/v1/search?name=${encodeURIComponent(cidade)}&count=1&language=pt&format=json`);
    if (!g.results?.length) return { erro: `cidade "${cidade}" não encontrada` };
    geo = g.results[0];
    cacheGeo.set(cidade.toLowerCase(), geo);
  }
  const d = await pegar(`https://api.open-meteo.com/v1/forecast?latitude=${geo.latitude}&longitude=${geo.longitude}` +
    '&current=temperature_2m,apparent_temperature,relative_humidity_2m,weather_code,wind_speed_10m' +
    '&daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max,weather_code&timezone=auto&forecast_days=2');
  const c = d.current, dd = d.daily;
  return {
    cidade: `${geo.name}${geo.admin1 ? ', ' + geo.admin1 : ''}`,
    agora: { temperatura: Math.round(c.temperature_2m), sensacao: Math.round(c.apparent_temperature), umidade: c.relative_humidity_2m, vento_kmh: Math.round(c.wind_speed_10m), condicao: CODIGOS[c.weather_code] || 'indefinido' },
    hoje: { max: Math.round(dd.temperature_2m_max[0]), min: Math.round(dd.temperature_2m_min[0]), chance_chuva: dd.precipitation_probability_max[0], condicao: CODIGOS[dd.weather_code[0]] },
    amanha: { max: Math.round(dd.temperature_2m_max[1]), min: Math.round(dd.temperature_2m_min[1]), chance_chuva: dd.precipitation_probability_max[1], condicao: CODIGOS[dd.weather_code[1]] }
  };
}

const NOMES_MOEDA = { dolar: 'USD', 'dólar': 'USD', usd: 'USD', euro: 'EUR', eur: 'EUR', bitcoin: 'BTC', btc: 'BTC', libra: 'GBP', gbp: 'GBP',
  iene: 'JPY', ethereum: 'ETH', eth: 'ETH', peso: 'ARS', 'peso argentino': 'ARS', 'dolar canadense': 'CAD', 'franco suico': 'CHF', yuan: 'CNY' };
export async function cotacao(moedas) {
  let lista = (Array.isArray(moedas) ? moedas : String(moedas || 'dolar,euro,bitcoin').split(/\s*(?:,|;|\se\s)\s*/))
    .map(m => NOMES_MOEDA[String(m).trim().toLowerCase()] || String(m).trim().toUpperCase()).filter(m => /^[A-Z]{3}$/.test(m));
  if (!lista.length) lista = ['USD', 'EUR', 'BTC'];
  const d = await pegar(`https://economia.awesomeapi.com.br/json/last/${[...new Set(lista)].map(m => m + '-BRL').join(',')}`);
  const saida = {};
  for (const k in d) saida[d[k].code] = { nome: d[k].name.split('/')[0], valor_reais: Number(d[k].bid), variacao_pct: Number(d[k].pctChange) };
  return saida;
}

// ── NOTÍCIAS ───────────────────────────────────────────────────
export async function noticias(tema) {
  const url = tema
    ? `https://news.google.com/rss/search?q=${encodeURIComponent(tema)}&hl=pt-BR&gl=BR&ceid=BR:pt-419`
    : 'https://news.google.com/rss?hl=pt-BR&gl=BR&ceid=BR:pt-419';
  const xml = await pegar(url, 'texto');
  const itens = [...xml.matchAll(/<item>[\s\S]*?<title>([\s\S]*?)<\/title>[\s\S]*?<\/item>/g)].slice(0, 6)
    .map(m => m[1].replace(/<!\[CDATA\[|\]\]>/g, '').replace(/&amp;/g, '&').replace(/&quot;/g, '"').replace(/&#39;/g, "'").trim());
  return { tema: tema || 'principais', manchetes: itens };
}

// ── WIKIPÉDIA ──────────────────────────────────────────────────
export async function wikipedia(termo) {
  const busca = await pegar(`https://pt.wikipedia.org/w/api.php?action=opensearch&search=${encodeURIComponent(termo)}&limit=1&namespace=0&format=json`);
  const titulo = busca?.[1]?.[0];
  if (!titulo) return { erro: 'nada encontrado' };
  const r = await pegar(`https://pt.wikipedia.org/api/rest_v1/page/summary/${encodeURIComponent(titulo)}`);
  return { titulo: r.title, resumo: String(r.extract || '').slice(0, 1200) };
}

const PASTA = process.env.PASTA_DADOS || path.join(path.dirname(fileURLToPath(import.meta.url)), 'dados');
const ARQ = path.join(PASTA, 'memoria.json');
export function lerMemoria() {
  try { return JSON.parse(fs.readFileSync(ARQ, 'utf8')); } catch { return []; }

export function lembrar(fato) {
  fato = String(fato || '').trim().slice(0, 300);
  if (!fato) return { erro: 'fato vazio' };
  const m = lerMemoria().filter(x => x.fato.toLowerCase() !== fato.toLowerCase());
  m.push({ fato, quando: new Date().toISOString() });
  fs.mkdirSync(PASTA, { recursive: true });
  fs.writeFileSync(ARQ, JSON.stringify(m.slice(-80), null, 2));
  return { ok: true, total: m.length };
}
export function esquecer(trecho) {
  const t = String(trecho || '').toLowerCase().trim();
  const antes = lerMemoria();
  const depois = t ? antes.filter(x => !x.fato.toLowerCase().includes(t)) : antes;
  fs.mkdirSync(PASTA, { recursive: true });
  fs.writeFileSync(ARQ, JSON.stringify(depois, null, 2));
  return { removidos: antes.length - depois.length };
}

export async function executarFerramenta(f) {
  const nome = String(f?.nome || '').toLowerCase();
  try {
    if (nome === 'clima') return await clima(f.cidade);
    if (nome === 'cotacao') return await cotacao(f.moedas);
    if (nome === 'noticias') return await noticias(f.tema);
    if (nome === 'wikipedia') return await wikipedia(f.termo || f.tema);
    if (nome === 'lembrar') return lembrar(f.fato);
    if (nome === 'esquecer') return esquecer(f.trecho || f.fato);
    if (nome === 'memoria') return { fatos: lerMemoria().map(x => x.fato) };
    return { erro: 'ferramenta desconhecida' };
  } catch (e) {
    return { erro: `falha ao consultar: ${e.message}` };
  }
}

  const dados = { clima: c.status === 'fulfilled' && !c.value.erro ? c.value : null, cotacao: q.status === 'fulfilled' ? q.value : null };
  if (dados.clima || dados.cotacao) painelCache = { t: Date.now(), dados };
  return dados;
}

// ═══════════════════════════════════════════════════════════════
//  CASA INTELIGENTE — liga/desliga aparelhos (luz, TV, tomada…)
//  Funciona de dois jeitos, sem programar:
//   1) WEBHOOK: você cola o link "ligar" e "desligar" de cada
//      aparelho (IFTTT, Tuya/Smart Life, SmartThings, Home
//      Assistant, etc.). Mais fácil e funciona pela nuvem.
//   2) HOME ASSISTANT: endereço + token e o id da entidade.
//  Config: arquivo dados/casa.json (editável pela tela /casa) e/ou
//  a variável de ambiente CASA_JSON (persistente no Render).
// ═══════════════════════════════════════════════════════════════
import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const DIR = process.env.PASTA_DADOS || path.join(path.dirname(fileURLToPath(import.meta.url)), 'dados');
const ARQ = path.join(DIR, 'casa.json');

const semAcento = s => String(s || '').toLowerCase().normalize('NFD').replace(/[̀-ͯ]/g, '').trim();

export function lerConfig() {
  let cfg = { dispositivos: [], ha: {} };
  try { cfg = { ...cfg, ...JSON.parse(fs.readFileSync(ARQ, 'utf8')) }; } catch {}
  if (process.env.CASA_JSON) {
    try {
      const env = JSON.parse(process.env.CASA_JSON);
      const porNome = new Map(cfg.dispositivos.map(d => [semAcento(d.nome), d]));
      for (const d of (env.dispositivos || [])) porNome.set(semAcento(d.nome), d);
      cfg.dispositivos = [...porNome.values()];
      if (env.ha) cfg.ha = { ...cfg.ha, ...env.ha };
    } catch {}
  }
  return cfg;
}

export function salvarConfig(cfg) {
  fs.mkdirSync(DIR, { recursive: true });
  const limpo = {
    dispositivos: (cfg.dispositivos || []).filter(d => d && d.nome).slice(0, 60).map(d => ({
      nome: String(d.nome).slice(0, 40),
      tipo: d.tipo === 'ha' ? 'ha' : 'webhook',
      ligar: String(d.ligar || '').slice(0, 500),
      desligar: String(d.desligar || '').slice(0, 500),
      metodo: /^(GET|POST)$/i.test(d.metodo) ? d.metodo.toUpperCase() : 'POST',
      entidade: String(d.entidade || '').slice(0, 80)
    })),
    ha: { url: String(cfg.ha?.url || '').slice(0, 300), token: String(cfg.ha?.token || '').slice(0, 400) }
  };
  fs.writeFileSync(ARQ, JSON.stringify(limpo, null, 2));
  return limpo;
}

export function listar() {
  const cfg = lerConfig();
  return cfg.dispositivos.map(d => ({ nome: d.nome, tipo: d.tipo, temLigar: !!(d.ligar || d.entidade), temDesligar: !!(d.desligar || d.entidade) }));
}

function achar(cfg, alvo) {
  const a = semAcento(alvo);
  if (!a) return [];
  if (/\b(tudo|tudos|geral|casa inteira)\b/.test(a)) return cfg.dispositivos.slice();
  // casamento por nome contido (nos dois sentidos)
  const exato = cfg.dispositivos.filter(d => semAcento(d.nome) === a);
  if (exato.length) return exato;
  return cfg.dispositivos.filter(d => { const n = semAcento(d.nome); return n && (a.includes(n) || n.includes(a)); });
}

async function acionarUm(cfg, d, acao) {
  const ligar = acao === 'ligar';
  if (d.tipo === 'ha') {
    const base = (cfg.ha?.url || '').replace(/\/+$/, '');
    if (!base || !cfg.ha?.token) throw new Error('Home Assistant não configurado');
    const dominio = (d.entidade || '').split('.')[0] || 'homeassistant';
    const r = await fetch(`${base}/api/services/${dominio}/${ligar ? 'turn_on' : 'turn_off'}`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${cfg.ha.token}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({ entity_id: d.entidade }),
      signal: AbortSignal.timeout(9000)
    });
    if (!r.ok) throw new Error(`HA HTTP ${r.status}`);
    return true;
  }
  const url = ligar ? d.ligar : d.desligar;
  if (!url) throw new Error(`sem link de ${ligar ? 'ligar' : 'desligar'} para ${d.nome}`);
  const r = await fetch(url, { method: d.metodo || 'POST', signal: AbortSignal.timeout(9000) });
  if (!r.ok) throw new Error(`HTTP ${r.status}`);
  return true;
}

// acao: 'ligar' | 'desligar' ; alvo: nome do aparelho ou "tudo"
export async function acionar(acao, alvo) {
  const cfg = lerConfig();
  if (!cfg.dispositivos.length) return { ok: false, motivo: 'nenhum_dispositivo' };
  acao = acao === 'desligar' ? 'desligar' : 'ligar';
  const alvos = achar(cfg, alvo);
  if (!alvos.length) return { ok: false, motivo: 'nao_encontrado', alvo };
  const feitos = [], falhas = [];
  for (const d of alvos) {
    try { await acionarUm(cfg, d, acao); feitos.push(d.nome); }
    catch (e) { falhas.push({ nome: d.nome, erro: e.message }); }
  }
  return { ok: feitos.length > 0, acao, feitos, falhas };
}

// Detecta "liga/desliga <aparelho>" no texto, só se houver aparelho configurado.
export function comandoDoTexto(texto) {
  const t = semAcento(texto);
  const desliga = /\b(desliga|desligar|desligue|apaga|apague|apagar|desativa|desativar|desative)\b/.test(t);
  const liga = /\b(liga|ligar|ligue|acende|acenda|acender|ativa|ativar|ative|abre a luz)\b/.test(t);
  if (!liga && !desliga) return null;
  const cfg = lerConfig();
  if (!cfg.dispositivos.length) return null;
  const acao = desliga ? 'desligar' : 'ligar';
  if (/\b(tudo|geral|casa inteira|todas as luzes|tudos)\b/.test(t)) return { acao, alvo: 'tudo' };
  // procura algum aparelho configurado citado no texto
  const bate = cfg.dispositivos.find(d => { const n = semAcento(d.nome); return n && t.includes(n); });
  if (bate) return { acao, alvo: bate.nome };
  // palavras-chave comuns que batem com um aparelho configurado
  for (const chave of ['luz', 'lampada', 'tv', 'televisao', 'tomada', 'ar condicionado', 'ventilador', 'som']) {
    if (t.includes(chave)) {
      const d = cfg.dispositivos.find(x => semAcento(x.nome).includes(chave));
      if (d) return { acao, alvo: d.nome };
    }
  }
  return null;
}

    if (e.error === 'not-allowed') { legendaJarvis('Permita o uso do microfone no navegador (ícone de cadeado ao lado do endereço).', true); desligar(); }
    else if (e.error === 'audio-capture') { legendaJarvis('Nenhum microfone encontrado. Verifique se ele está conectado.', true); desligar(); }
    else if (e.error === 'network' || e.error === 'service-not-allowed' || e.error === 'language-not-supported') {
      // navegador sem o serviço de voz (Brave, Opera, etc.) → usa Whisper do servidor
      modoOuvido = 'servidor'; atualizarHudOuvido();
      legendaVoce('trocando para o ouvido do servidor…');
    } else if (e.error !== 'no-speech' && e.error !== 'aborted') {
      errosSeguidos++;
    }
  };
  r.onend = () => {
    recRodando = false;
    if (ativo && estado === 'ouvindo') {
      if (modoOuvido === 'servidor') return ouvirServidor();
      setTimeout(() => { if (ativo && estado === 'ouvindo' && !recRodando) iniciarRec(); }, errosSeguidos > 3 ? 1500 : 150);
    }
  };
  return r;
}
function iniciarRec() {
  if (!rec) rec = criarRec();
  try { rec.start(); } catch {}
}
function pararRec() { if (rec) try { rec.abort(); } catch {} recRodando = false; }

// ── Whisper: grava quando você fala, para quando fica em silêncio
let gravador = null, laçoVAD = null;
async function ouvirServidor() {
  if (!saude.transcricao_servidor) {
    legendaJarvis('Este navegador não tem reconhecimento de voz e o servidor está sem a chave GROQ_API_KEY. Use o Google Chrome ou o Edge, ou configure a chave.', true);
    return;
  }
  try { await abrirMic(); } catch { legendaJarvis('Permita o uso do microfone no navegador.', true); return desligar(); }
  pararVAD();
  const tipos = ['audio/webm;codecs=opus', 'audio/webm', 'audio/mp4', 'audio/ogg;codecs=opus'];
  const mime = tipos.find(t => window.MediaRecorder && MediaRecorder.isTypeSupported(t)) || '';
  let piso = .01, gravando = false, inicio = 0, ultimaVoz = 0, pedacos = [];
  laçoVAD = setInterval(() => {
    if (!ativo || estado !== 'ouvindo') return pararVAD();
    const n = nivelMic();
    const limiar = Math.max(.025, piso * 2.8);
    const agora = performance.now();
    if (!gravando) {
      piso = piso * .97 + n * .03;
      if (n > limiar) {
        pedacos = [];
        gravador = new MediaRecorder(fluxoMic, mime ? { mimeType: mime } : undefined);
        gravador.ondataavailable = e => e.data.size && pedacos.push(e.data);
        gravador.onstop = () => enviarAudio(new Blob(pedacos, { type: gravador.mimeType || 'audio/webm' }), agora - inicio);
        gravador.start(); gravando = true; inicio = ultimaVoz = agora;
        legendaVoce('…', true);
      }
    } else {
      if (n > limiar) ultimaVoz = agora;
      if (agora - ultimaVoz > 1100 || agora - inicio > 15000) { gravando = false; try { gravador.stop(); } catch {} }
    }
  }, 50);
}
function pararVAD() { clearInterval(laçoVAD); laçoVAD = null; if (gravador && gravador.state === 'recording') { gravador.onstop = null; try { gravador.stop(); } catch {} } }

async function enviarAudio(blob, duracao) {
  if (duracao < 450 || blob.size < 2500) { legendaVoce(''); return; }
  pararVAD();
  mudarEstado('pensando', 'TRANSCREVENDO');
  try {
    const fd = new FormData(); fd.append('audio', blob, 'fala.' + (blob.type.includes('mp4') ? 'mp4' : 'webm'));
    const r = await fetch('/api/transcribe', { method: 'POST', body: fd });
    const d = await r.json();
    if (!r.ok) throw new Error(d.mensagem || d.error);
    const txt = (d.text || '').trim();
    if (!txt || /^(obrigad[oa]|tchau|legendas pela comunidade.*)\.?$/i.test(txt)) { voltarAOuvir(); return; }
    processar(txt, true);
  } catch (e) {
    legendaJarvis('Falha na transcrição: ' + e.message, true);
    voltarAOuvir();
  }
}

function urlDaAcao(a) {
  if (a.tipo === 'abrir_site' && a.url) return /^https?:\/\//.test(a.url) ? a.url : 'https://' + a.url;
  if (a.tipo === 'pesquisar' && a.termo) return 'https://www.google.com/search?q=' + encodeURIComponent(a.termo);
  if (a.tipo === 'youtube' && a.termo) return 'https://www.youtube.com/results?search_query=' + encodeURIComponent(a.termo);
  if (a.url) return a.url;
  return null;
}
async function executarAcao(a) {
  if (!a || typeof a !== 'object') return;
  if (a.tipo === 'interface') return trocarModo(a.modo);
  if (a.tipo === 'timer') return criarTimer(a.segundos, a.mensagem);
  if (a.tipo === 'tela') {
    if (a.sub === 'parar') return pararTela(true);
    if (a.sub === 'vigiar') return vigiarTela();
    return descreverTela(a.pergunta || '');
  }
  const url = urlDaAcao(a);
  if (saude.comandos_pc) {
    try {
      const r = await (await fetch('/api/pc/acao', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(url ? { url } : a) })).json();
      if (r.ok) return;
    } catch {}
  }
  if (url) {
    const w = window.open(url, '_blank', 'noopener');
    if (!w) { el.linkA.href = url; el.linkA.textContent = 'TOQUE PARA ABRIR ↗'; el.link.style.display = 'block'; }
  } else if (a.tipo === 'abrir_app' || a.tipo === 'sistema') {
    legendaVoce('isso só funciona com o Jarvis rodando no seu computador');
  }
}

// legenda palavra por palavra (blocos de até 7 palavras, como nos vídeos)
function digitar(texto, ms) {
  const ini = performance.now();
  const palavras = texto.split(/\s+/).filter(Boolean);
  const BLOCO = celular ? 5 : 7;
  const esc = w => w.replace(/[&<>]/g, c => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;' }[c]));
  let ultimoIdx = -1;
  el.jarvis.classList.add('karaoke');
  return setInterval(() => {
    const k = Math.min(1, (performance.now() - ini) / Math.max(400, ms));
    const idx = Math.min(palavras.length - 1, Math.floor(k * palavras.length));
    if (idx === ultimoIdx) return;
    ultimoIdx = idx;
    const ini2 = Math.floor(idx / BLOCO) * BLOCO;
    el.jarvis.innerHTML = palavras.slice(ini2, ini2 + BLOCO)
      .map((w, i) => `<span class="w${ini2 + i <= idx ? ' dita' : ''}">${esc(w)}</span>`).join(' ');
  }, 40);
}

async function falar(texto, audioUrl) {
  if (!texto) return;
  legendaJarvis('', false);
  if (mudo) { legendaJarvis(texto); return; }
  mudarEstado('falando');
  try {
    let url = audioUrl, local = false;
    if (!url && saude.voz_motor && saude.voz_motor !== 'navegador') {
      const r = await fetch('/api/tts', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ text: texto }) });
      if (!r.ok) throw new Error('tts');
      url = URL.createObjectURL(await r.blob()); local = true;
    }
    if (!url) throw new Error('sem voz');
    await tocar(url, texto, local);
  } catch {
    await vozNavegador(texto);
  }
  nivelVoz = 0;
  legendaJarvis(texto);
}

function tocar(url, texto, analisar) {
  return new Promise((ok, falha) => {
    const au = new Audio(url);
    audioAtual = au;
    let timer = null, laço = null;
    au.onloadedmetadata = () => { timer = digitar(texto, au.duration * 1000 * .9); };
    if (analisar && ctxAudio) {
      try {
        const src = ctxAudio.createMediaElementSource(au);
        const an = ctxAudio.createAnalyser(); an.fftSize = 512;
        const buf = new Uint8Array(an.fftSize);
        src.connect(an); an.connect(ctxAudio.destination);
        laço = setInterval(() => {
          an.getByteTimeDomainData(buf);
          let s = 0; for (let i = 0; i < buf.length; i++) { const v = (buf[i] - 128) / 128; s += v * v; }
          nivelVoz = Math.min(1, Math.sqrt(s / buf.length) * 5);
        }, 33);
      } catch {}
    } else {
      laço = setInterval(() => { nivelVoz = .3 + Math.random() * .5; }, 90);
    }
    const fim = (erro) => { clearInterval(timer); clearInterval(laço); nivelVoz = 0; audioAtual = null; erro ? falha(erro) : ok(); };
    au.onended = () => fim();
    au.onerror = () => fim(new Error('audio'));
    au.play().catch(fim);
  });
}

function vozNavegador(texto) {
  return new Promise(ok => {
    if (!('speechSynthesis' in window)) return ok();
    const u = new SpeechSynthesisUtterance(texto);
    u.lang = 'pt-BR'; u.rate = 1.05; u.pitch = .9;
    const vozes = speechSynthesis.getVoices().filter(v => v.lang.replace('_', '-').toLowerCase().startsWith('pt-br'));
    u.voice = vozes.find(v => /daniel|antonio|male|masculin/i.test(v.name)) || vozes.find(v => /google/i.test(v.name)) || vozes[0] || null;
    const timer = digitar(texto, texto.length * 65);
    const laço = setInterval(() => { nivelVoz = .25 + Math.random() * .55; }, 90);
    const fim = () => { clearInterval(timer); clearInterval(laço); nivelVoz = 0; ok(); };
    u.onend = fim; u.onerror = fim;
    speechSynthesis.cancel();
    speechSynthesis.speak(u);
    setTimeout(fim, 4000 + texto.length * 120); // segurança
  });
}

function criarTimer(segundos, mensagem) {
  segundos = Math.max(1, Math.min(86400 * 7, Number(segundos) || 60));
  timers.push({ fim: Date.now() + segundos * 1000, msg: String(mensagem || '').slice(0, 120) });
  salvarTimers(); mostrarTimers();
}
function fmtTempo(ms) {
  const s = Math.max(0, Math.ceil(ms / 1000)), h = Math.floor(s / 3600), m = Math.floor(s % 3600 / 60), ss = s % 60;
  return (h ? h + ':' + String(m).padStart(2, '0') : m) + ':' + String(ss).padStart(2, '0');
}
function mostrarTimers() {
  $('hudTimers').innerHTML = timers.map(t => `<div>⏱ ${fmtTempo(t.fim - Date.now())}${t.msg ? ' · ' + t.msg.replace(/[<>&]/g, '') : ''}</div>`).join('');
}
function bipe(vezes = 3) {
  garantirAudio();
  for (let i = 0; i < vezes; i++) {
    const o = ctxAudio.createOscillator(), gn = ctxAudio.createGain(), t0 = ctxAudio.currentTime + i * .32;
    o.type = 'sine'; o.frequency.setValueAtTime(880, t0); o.frequency.setValueAtTime(1320, t0 + .1);
    gn.gain.setValueAtTime(0, t0); gn.gain.linearRampToValueAtTime(.18, t0 + .02); gn.gain.exponentialRampToValueAtTime(.001, t0 + .25);
    o.connect(gn); gn.connect(ctxAudio.destination); o.start(t0); o.stop(t0 + .3);
  }
}

//  BUSTO — geometria compartilhada (coordenadas normalizadas:
//  u = horizontal a partir do centro, v = vertical a partir do topo)

function criarBusto(fem) {
  const kL = fem ? .84 : 1, queixo = fem ? .56 : .575, vc = fem ? .25 : .26;
  const cabeca = v => {
    if (v < 0 || v > queixo) return 0;
    let w;
    if (v <= vc) { const t = (v - vc) / vc; w = .2 * Math.sqrt(Math.max(0, 1 - t * t)); }
    else { const t = (v - vc) / (queixo - vc); w = .2 * Math.sqrt(Math.max(0, 1 - t * t)) * (1 - (fem ? .3 : .22) * t); }
    if (!fem) w += .016 * Math.exp(-(((v - .3) / .035) ** 2));
    return w * kL;
  };
  // ombros (curvas de Bézier amostradas)
  const seg = fem
    ? [[[.085, .62], [.09, .75], [.32, .73], [.45, .83]], [[.45, .83], [.53, .89], [.53, 1.0], [.52, 1.6]]]
    : [[[.112, .62], [.118, .745], [.40, .75], [.58, .86]], [[.58, .86], [.70, .93], [.74, 1.0], [.77, 1.6]]];
  const tab = [];
  seg.forEach(s => { for (let i = 0; i <= 80; i++) tab.push(cubica(...s, i / 80)); });
  tab.sort((a, b) => a[1] - b[1]);
  const pescocoTopo = .47, pesc0 = fem ? .078 : .105;
  const corpo = v => {
    if (v < pescocoTopo) return 0;
    if (v < seg[0][0][1]) return pesc0 + (seg[0][0][0] - pesc0) * (v - pescocoTopo) / (seg[0][0][1] - pescocoTopo);
    if (v >= tab[tab.length - 1][1]) return tab[tab.length - 1][0];
    let i = 1; while (tab[i][1] < v) i++;
    const a = tab[i - 1], b = tab[i], k = (v - a[1]) / Math.max(1e-6, b[1] - a[1]);
    return a[0] + (b[0] - a[0]) * k;
  };
  const dentroCorpo = (u, v) => v > pescocoTopo + .02 && Math.abs(u) < corpo(v) - .004;
  return { cabeca, corpo, dentroCorpo, queixo, vc, pescocoTopo, fem };
}

    const fimParticulas = 1 - lim((tm - 2.5) / .7);
    // esfera de luz
    const ox = H.X(orbe[0]), oy = H.Y(orbe[1]);
    const brilhoOrbe = tm < 2.6 ? lim(tm / .3) : .35 + P.nivel * .4;
    const go = g.createRadialGradient(ox, oy, 0, ox, oy, H.S * (tm < 2.6 ? .07 : .035));
    go.addColorStop(0, `rgba(255,255,255,${brilhoOrbe})`); go.addColorStop(.25, corOrbe(brilhoOrbe * .9)); go.addColorStop(1, corOrbe(0));
    g.globalCompositeOperation = 'lighter';
    g.fillStyle = go; g.fillRect(ox - H.S * .1, oy - H.S * .1, H.S * .2, H.S * .2);
    if (fimParticulas <= 0) { g.globalCompositeOperation = 'source-over'; return; }
    for (const a of H.amostras) {
      const k = suave((tm - a.atraso) / 1.25);
      if (k <= 0) continue;
      const c = [orbe[0] + a.cu, orbe[1] - a.cv];
      const m = 1 - k;
      const u = m * m * orbe[0] + 2 * m * k * c[0] + k * k * a.u + Math.sin(k * 9 + a.atraso * 7) * .01 * m;
      const v = m * m * orbe[1] + 2 * m * k * c[1] + k * k * a.v;
      g.globalAlpha = fimParticulas * (.35 + .65 * k);
      g.fillStyle = a.cor;
      const s = 1.1 + (1 - k) * 1.4;
      g.fillRect(H.X(u) - s / 2, H.Y(v) - s / 2, s, s);
    }
    g.globalAlpha = 1; g.globalCompositeOperation = 'source-over';
  };
  return H;
}

// anéis de HUD (marcas, arcos e leitura de dados) em volta da cabeça
function anelHUD(cx, cy, S, t, n, aparece, rgb) {
  const R = S * .335;
  const vel = P.estado === 'pensando' ? 1.6 : .25 + n * .8;
  g.save();
  g.translate(cx, cy);
  g.globalCompositeOperation = 'lighter';
  g.strokeStyle = `rgb(${rgb})`; g.fillStyle = `rgb(${rgb})`;
  // arco externo segmentado
  g.lineWidth = 1.2; g.globalAlpha = (.22 + n * .3) * aparece;
  for (let k = 0; k < 6; k++) {
    const a0 = t * vel * .5 + k * Math.PI / 3;
    g.beginPath(); g.arc(0, 0, R * 1.08, a0, a0 + Math.PI / 5); g.stroke();
  }
  // marcas de escala
  g.globalAlpha = (.18 + n * .25) * aparece; g.lineWidth = 1;
  g.beginPath();
  for (let k = 0; k < 72; k++) {
    const a = -t * vel * .3 + k * Math.PI / 36, r1 = R * (k % 6 ? 1.0 : .97);
    g.moveTo(Math.cos(a) * r1, Math.sin(a) * r1); g.lineTo(Math.cos(a) * R * 1.02, Math.sin(a) * R * 1.02);
  }
  g.stroke();
  // arco de intensidade (mostra o volume da voz)
  g.globalAlpha = (.35 + n * .5) * aparece; g.lineWidth = 2.4;
  g.beginPath(); g.arc(0, 0, R * 1.15, -Math.PI * .25, -Math.PI * .25 + Math.PI * .5 * (.08 + n * .92)); g.stroke();
  g.globalAlpha = .12 * aparece; g.lineWidth = 2.4;
  g.beginPath(); g.arc(0, 0, R * 1.15, -Math.PI * .25, Math.PI * .25); g.stroke();
  // pontos orbitando
  g.globalAlpha = .8 * aparece;
  for (let k = 0; k < 3; k++) {
    const a = t * (vel + .3) * (k % 2 ? -1 : 1) + k * 2.1, r = R * (1.08 + k * .035);
    g.fillRect(Math.cos(a) * r - 1.5, Math.sin(a) * r - 1.5, 3, 3);
  }
  g.restore();
}

// ════════════════════════════════════════════════════════════════
//  MODO 2 — HOLOGRAMA (ciano + núcleo laranja)
// ════════════════════════════════════════════════════════════════
const holograma = (() => {
  const H = baseHolo(false);
  const B = H.B;
  let terreno = null, brilhosTerreno = [], veias = [], halo = [];
  const CIANO = 'rgb(95,230,255)', LARANJA = 'rgb(255,170,60)';

  function gerarVeias() {
    const linhas = [];
    const ramo = (x, y, ang, comp, prof) => {
      const pts = [[x, y]]; let a = ang; const passos = 9;
      for (let i = 0; i < passos; i++) {
        a += rnd(-.38, .38); a = lim(a, -.9, .9);
        x += Math.sin(a) * comp / passos; y += Math.cos(a) * comp / passos;
        if (!B.dentroCorpo(x, y) && y > .62) break;
        pts.push([x, y]);
        if (prof < 3 && Math.random() < .2) ramo(x, y, a + (Math.random() < .5 ? -1 : 1) * rnd(.45, .9), comp * .5, prof + 1);
      }
      linhas.push({ pts, prof, fase: rnd(0, 6.28) });
    };
    ramo(0, .565, 0, .3, 0);
    ramo(-.025, .6, -.18, .26, 1); ramo(.025, .6, .18, .26, 1);
    ramo(-.05, .66, -.5, .2, 2); ramo(.05, .66, .5, .2, 2);
    return linhas;
  }

  function gerarTerreno() {
    const [c, cg] = novaCamada();
    brilhosTerreno = [];
    const camadas = celular ? 6 : 9;
    const passo = celular ? 2.4 : 2;
    // de trás para a frente: cada camada mais próxima cobre a anterior
    for (let j = 0; j < camadas; j++) {
      const perto = (j + 1) / camadas;
      const base = A * (.5 + j * .052), amp = A * (.09 + perto * .13);
      const f = [rnd(.0025, .0045), rnd(.008, .013), rnd(.02, .032)], fa = [rnd(0, 6), rnd(0, 6), rnd(0, 6)];
      const fr = rnd(.004, .008), frp = rnd(0, 6);
      const cume = [];
      for (let x = -4; x <= L + 4; x += passo) {
        const pico = k => 1 - Math.abs(Math.sin(x * f[k] + fa[k]));
        const h = .58 * pico(0) ** 1.3 + .28 * pico(1) + .14 * pico(2);
        const lado = .35 + 1.15 * Math.min(1, Math.abs(x - L / 2) / (L * .5));
        cume.push([x, base - amp * lado * h, lado]);
      }
      // corpo escuro da montanha (esconde as camadas de trás)
      cg.fillStyle = 'rgba(2,5,11,.93)';
      cg.beginPath(); cg.moveTo(-4, A);
      for (const [x, y] of cume) cg.lineTo(x, y);
      cg.lineTo(L + 4, A); cg.closePath(); cg.fill();
      for (const [x, y, lado] of cume) {
        const a = (.3 + .65 * perto) * rnd(.55, 1);
        cg.fillStyle = `rgba(90,210,255,${a})`;
        cg.fillRect(x, y, 1.4, 1.4);
        if (Math.random() < .02) brilhosTerreno.push([x, y]);
        // encosta com pontos (mais densos perto do cume)
        for (let k = 0; k < 9; k++) {
          const d = Math.pow(Math.random(), 2.2) * amp * lado;
          cg.fillStyle = `rgba(55,165,235,${a * (1 - d / (amp * lado + 1)) * rnd(.25, .7)})`;
          cg.fillRect(x + rnd(-1.5, 1.5), y + d, 1.1, 1.1);
        }
        // rios de lava nos vales
        if (Math.sin(x * fr + frp) > .35 && Math.random() < .5) {
          const d = rnd(.08, .45) * amp * lado;
          cg.fillStyle = `rgba(255,${rnd(120, 200) | 0},50,${(.35 + .6 * perto) * rnd(.4, 1)})`;
          cg.fillRect(x, y + d, 1.5, 1.5);
          if (Math.random() < .03) brilhosTerreno.push([x, y + d]);
        }
      }
    }
    // some suavemente no alto
    const fade = cg.createLinearGradient(0, A * .25, 0, A * .5);
    fade.addColorStop(0, 'rgba(0,0,0,1)'); fade.addColorStop(1, 'rgba(0,0,0,0)');
    cg.globalCompositeOperation = 'destination-out';
    cg.fillStyle = fade; cg.fillRect(0, 0, L, A * .5);
    cg.globalCompositeOperation = 'source-over';
    return c;
  }

  function gerarEstatico() {
    H.linhas = [];
    // linhas horizontais da cabeça
    for (let v = .018; v < B.queixo - .008; v += .0115) {
      const hw = B.cabeca(v) * .985, pts = [];
      for (let i = 0; i <= 30; i++) { const u = -hw + 2 * hw * i / 30; pts.push([u, v + .008 * (1 - (u / hw) ** 2)]); }
      H.linhas.push({ pts, cor: CIANO, alfa: .55, larg: 1.05, cor2: v > .14 && v < .5 ? LARANJA : CIANO });
    }
    // anéis do peito e ombros
    const vAnel = Math.max(1.27, H.vMax + .15);
    for (let r = .12; r < 1.9; r += .021) {
      let atual = [];
      const fechar = () => { if (atual.length > 2) H.linhas.push({ pts: atual, cor: CIANO, alfa: .3, larg: .9 }); atual = []; };
      for (let a = Math.PI; a <= Math.PI * 2; a += .012) {
        const u = Math.cos(a) * r, v = vAnel + Math.sin(a) * r * .6;
        if (B.dentroCorpo(u, v) && v < H.vMax) atual.push([u, v]); else fechar();
      }
      fechar();
    }
    // linhas do pescoço
    for (let k = -4; k <= 4; k++) {
      const pts = [];
      for (let v = .52; v < .72; v += .01) pts.push([k * .022 * (1 + (v - .52) * 1.6), v]);
      H.linhas.push({ pts, cor: CIANO, alfa: .18, larg: .8 });
    }
    veias = gerarVeias();
    H.amostrar(celular ? 1100 : 2000);

    const [c, cg] = novaCamada();
    cg.fillStyle = 'rgba(2,6,14,.94)';
    H.caminhoCorpo(cg); cg.fill();
    H.caminhoCabeca(cg); cg.fill();
    cg.globalCompositeOperation = 'lighter';
    cg.lineCap = 'round';
    for (const l of H.linhas) {
      cg.globalAlpha = l.alfa; cg.strokeStyle = l.cor; cg.lineWidth = l.larg;
      H.desenharLinha(cg, l.pts); cg.stroke();
    }
    // contornos com brilho
    cg.globalAlpha = 1;
    cg.shadowColor = '#00c8ff';
    const contornos = [H.contornoCabeca(), H.contornoCorpo(-1), H.contornoCorpo(1)];
    for (const [larg, blur, cor] of [[6, 26, 'rgba(0,170,255,.35)'], [2.6, 14, 'rgba(110,235,255,.95)'], [1.1, 4, 'rgba(230,255,255,.9)']]) {
      cg.lineWidth = larg; cg.shadowBlur = blur * DPR; cg.strokeStyle = cor;
      for (const pts of contornos) { H.desenharLinha(cg, pts); cg.stroke(); }
    }
    cg.shadowBlur = 0;
    // contorno interno da cabeça
    cg.globalAlpha = .5; cg.lineWidth = 1; cg.strokeStyle = CIANO;
    cg.beginPath();
    for (let v = .03; v <= B.queixo - .03; v += .004) cg.lineTo(H.X(B.cabeca(v) * .93), H.Y(v));
    cg.stroke(); cg.beginPath();
    for (let v = .03; v <= B.queixo - .03; v += .004) cg.lineTo(H.X(-B.cabeca(v) * .93), H.Y(v));
    cg.stroke();
    H.estatico = c;
  }

  function novaParticulaHalo(inicio) {
    const a = rnd(-Math.PI * .95, -Math.PI * .05);
    const r = 1 + rnd(0, .08);
    return { u: Math.cos(a) * .2 * r, v: .26 + Math.sin(a) * .27 * r, du: Math.cos(a) * rnd(.004, .02), dv: Math.sin(a) * rnd(.006, .025) - .006,
      vida: inicio ? rnd(0, 1) : 0, dur: rnd(1.5, 4) };
  }

  return {
    entrar() { H.t0 = tempo; if (!H.estatico) this.redim(); },
    redim() {
      H.layout(); terreno = gerarTerreno(); gerarEstatico();
      halo = Array.from({ length: celular ? 160 : 280 }, () => novaParticulaHalo(true));
    },
    desenhar(dt) {
      const tm = tempo - H.t0, t = tempo, n = P.nivel, S = H.S;
      const aparece = suave((tm - 2.1) / .8);
      // fundo
      g.fillStyle = '#02050b'; g.fillRect(0, 0, L, A);
      g.globalAlpha = .55 + .45 * suave(tm / 1.5);
      g.drawImage(terreno, 0, 0, L, A);
      g.globalCompositeOperation = 'lighter';
      for (let i = 0; i < 26; i++) {
        const p = brilhosTerreno[(Math.random() * brilhosTerreno.length) | 0];
        if (!p) break;
        g.globalAlpha = rnd(.3, .9); g.fillStyle = Math.random() < .3 ? LARANJA : CIANO;
        g.fillRect(p[0] - 1, p[1] - 1, 2.2, 2.2);
      }
      // anéis quando está ouvindo
      if (P.estado === 'ouvindo' || P.estado === 'pensando') {
        g.strokeStyle = CIANO; g.lineWidth = 1;
        for (let k = 0; k < 4; k++) {
          const f = (t * (P.estado === 'pensando' ? .9 : .45) + k / 4) % 1;
          g.globalAlpha = (1 - f) * (.1 + n * .5) * aparece;
          g.beginPath(); g.ellipse(H.X(0), H.Y(.29), S * (.24 + f * .35), S * (.31 + f * .35), 0, 0, Math.PI * 2); g.stroke();
        }
      }
      g.globalCompositeOperation = 'source-over'; g.globalAlpha = 1;
      if (aparece > 0) {
        g.globalAlpha = aparece;
        g.drawImage(H.estatico, 0, 0, L, A);
        if (n > .05) { g.globalCompositeOperation = 'lighter'; g.globalAlpha = aparece * n * .55; g.drawImage(H.estatico, 0, 0, L, A); }
        g.globalCompositeOperation = 'lighter';
        // núcleo laranja do rosto
        const fx = H.X(0), fy = H.Y(.33);
        const forca = (.5 + P.brilho * .25 + n * .6) * aparece;
        const nucleo = g.createRadialGradient(fx, fy, 0, fx, fy, S * (.19 + n * .04));
        nucleo.addColorStop(0, `rgba(255,240,170,${.75 * forca})`);
        nucleo.addColorStop(.35, `rgba(255,160,40,${.55 * forca})`);
        nucleo.addColorStop(.75, `rgba(255,90,10,${.18 * forca})`);
        nucleo.addColorStop(1, 'rgba(255,80,0,0)');
        g.globalAlpha = 1; g.fillStyle = nucleo; g.fillRect(fx - S * .3, fy - S * .3, S * .6, S * .6);
        // ondas do rosto
        const amp = .0022 + n * .013 + (P.estado === 'pensando' ? .004 : 0);
        const vel = 3 + n * 6 + P.energia * 2;
        g.lineWidth = 1.3;
        for (let v = .12; v < .53; v += .0115) {
          const hw = B.cabeca(v) * .9;
          const a = forca * Math.exp(-(((v - .33) / .14) ** 2));
          if (a < .03) continue;
          const lg = g.createLinearGradient(H.X(-hw), 0, H.X(hw), 0);
          lg.addColorStop(0, 'rgba(255,140,40,0)');
          lg.addColorStop(.5, `rgba(255,${(200 + n * 50) | 0},${(90 + n * 90) | 0},${lim(a)})`);
          lg.addColorStop(1, 'rgba(255,140,40,0)');
          g.strokeStyle = lg; g.beginPath();
          for (let i = 0; i <= 28; i++) {
            const u = -hw + 2 * hw * i / 28;
            let dv = amp * Math.sin(u * 26 + t * vel + v * 9) + amp * .4 * Math.sin(u * 47 - t * vel * .7);
            if (P.estado === 'pensando') dv += .005 * Math.sin(Math.atan2(v - .33, u) * 3 + t * 5);
            const y = H.Y(v + .008 * (1 - (u / hw) ** 2) + dv);
            i ? g.lineTo(H.X(u), y) : g.moveTo(H.X(u), y);
          }
          g.stroke();
        }
        // veias
        g.lineCap = 'round';
        for (const ve of veias) {
          const pul = .45 + .35 * Math.sin(t * 2.2 + ve.fase) + n * .7;
          g.globalAlpha = lim(pul) * aparece * (1 - ve.prof * .15);
          g.strokeStyle = 'rgba(255,150,40,.9)'; g.lineWidth = 1.7 - ve.prof * .3;
          H.desenharLinha(g, ve.pts); g.stroke();
          g.globalAlpha *= .3; g.lineWidth = 5; g.stroke();
        }
        // anéis de HUD girando em volta da cabeça
        anelHUD(H.X(0), H.Y(.29), S, t, n, aparece, '95,230,255');
        // poeira de luz em volta da cabeça
        g.fillStyle = '#7fe6ff';
        for (let i = 0; i < halo.length; i++) {
          const p = halo[i];
          p.vida += dt / p.dur;
          if (p.vida >= 1) { halo[i] = novaParticulaHalo(false); continue; }
          const k = 1 + n * 3;
          p.u += p.du * dt * k; p.v += p.dv * dt * k;
          g.globalAlpha = Math.sin(p.vida * Math.PI) * .75 * aparece;
          g.fillRect(H.X(p.u), H.Y(p.v), 1.4, 1.4);
        }
        g.globalAlpha = 1; g.globalCompositeOperation = 'source-over';
        // texto de status
        g.globalAlpha = .85 * aparece;
        g.fillStyle = CIANO;
        g.font = `${Math.max(9, Math.round(S * .015))}px ui-monospace, Consolas, monospace`;
        if (L >= 640) { g.textAlign = 'right'; g.fillText(textoStatus(), H.X(-.42), H.Y(.12)); g.textAlign = 'left'; }
        g.textAlign = 'left'; g.globalAlpha = 1;
      }
      H.montagem(tm, a => `rgba(80,210,255,${a})`);
    }
  };
})();

// ════════════════════════════════════════════════════════════════
//  MODO 3 — TEMPESTADE (busto masculino neon, fumaça e raios)
// ════════════════════════════════════════════════════════════════
const tempestade = (() => {
  const H = baseHolo(false);
  const B = H.B;
  let fumacas = [], raios = [], brilhos = [];
  const LUZ = 'rgb(232,210,255)', OURO = 'rgb(255,190,110)', ROXO = 'rgb(170,110,255)', AZUL = 'rgb(140,170,255)';

  function linha(pts, cor, alfa, larg, filtrar) {
    if (filtrar) pts = pts.filter(p => B.dentroCorpo(p[0], p[1]));
    if (pts.length > 2) H.linhas.push({ pts, cor, alfa, larg });
  }
  const espelho = (fn) => { for (const s of [-1, 1]) fn(s); };

  function gerarEstatico() {
    H.linhas = [];
    // cabelo curto, penteado para cima (energia no topo da cabeça)
    const topoCab = u => B.vc - B.vc * Math.sqrt(Math.max(0, 1 - (u / .2) ** 2));
    for (let i = 0; i < (celular ? 46 : 70); i++) {
      const u0 = rnd(-.165, .165);
      const v0 = .105 + .07 * (u0 / .165) ** 2 + rnd(-.008, .008);
      const u3 = lim(u0 * 1.18 + rnd(-.015, .015), -.2, .2);
      const v3 = topoCab(u3) - rnd(.008, .04);
      linha(curva([u0, v0], [u0 * 1.05, v0 - .04], [u3 * .98, v3 + .05], [u3, v3], 18),
        Math.random() < .22 ? OURO : LUZ, rnd(.3, .75), rnd(.7, 1.4));
    }
    // costeletas
    for (let i = 0; i < 10; i++) {
      const s = i % 2 ? 1 : -1;
      linha(curva([s * rnd(.165, .18), rnd(.11, .14)], [s * rnd(.18, .19), .17], [s * rnd(.185, .195), .21], [s * rnd(.18, .19), rnd(.24, .28)], 12), LUZ, rnd(.3, .6), rnd(.7, 1.2));
    }
    espelho(s => {
      // rosto: maxilar, maçãs, sobrancelhas
      linha(curva([s * .19, .35], [s * .185, .46], [s * .11, .56], [s * .02, .573], 24), LUZ, .55, 1.3);
      linha(curva([s * .175, .28], [s * .15, .31], [s * .1, .345], [s * .06, .36], 16), ROXO, .35, 1);
      linha(curva([s * .155, .205], [s * .12, .19], [s * .06, .2], [s * .02, .215], 16), LUZ, .55, 1.4);
      // pescoço: esternocleidomastoideo e trapézio
      linha(curva([s * .12, .45], [s * .1, .55], [s * .06, .62], [s * .025, .68], 20), LUZ, .45, 1.1);
      linha(curva([s * .1, .55], [s * .14, .68], [s * .32, .72], [s * .47, .78], 26), LUZ, .55, 1.3, true);
      // clavículas
      linha(curva([s * .03, .695], [s * .15, .67], [s * .3, .72], [s * .42, .735], 24), OURO, .65, 1.4, true);
      // peitorais (várias linhas paralelas)
      for (let k = 0; k < 6; k++) {
        const o = k * .016;
        linha(curva([s * .015, .74 + o * .5], [s * (.04 + o * .3), .93 - o * .4], [s * (.3 - o), .96 - o], [s * (.43 - o * .8), .8 + o * .3], 30), k % 3 ? LUZ : OURO, .62 - k * .07, 1.4 - k * .12, true);
      }
      // deltoides
      for (let k = 0; k < 5; k++) {
        const o = k * .018;
        linha(curva([s * (.38 + o * .2), .745 + o * .3], [s * (.55 + o * .3), .74 + o], [s * (.66 - o * .2), .9], [s * (.6 - o * .3), 1.08], 28), k ? LUZ : OURO, .55 - k * .08, 1.3 - k * .12, true);
      }
      // linhas de energia descendo
      for (let k = 0; k < (celular ? 5 : 8); k++) {
        linha(curva([s * rnd(0, .03), rnd(.66, .7)], [s * rnd(.05, .15), rnd(.75, .85)], [s * rnd(.1, .25), rnd(.9, 1.05)], [s * rnd(.05, .3), rnd(1.05, 1.3)], 26),
          Math.random() < .4 ? OURO : AZUL, rnd(.2, .45), rnd(.6, 1.1), true);
      }
      // abdômen
      for (let k = 0; k < 3; k++) linha(curva([s * .015, 1.0 + k * .07], [s * .06, .99 + k * .07], [s * .11, 1.0 + k * .07], [s * .13, 1.03 + k * .07], 12), LUZ, .3, 1, true);
    });
    linha(curva([0, .7], [0, .85], [0, 1.0], [0, 1.25], 20), LUZ, .4, 1.1, true);
    // contornos suaves do rosto
    for (let v = .07; v < B.queixo - .02; v += .028) {

      for (let i = 1; i < pts.length; i++) {
        const a = pts[i - 1], b = pts[i], d = Math.hypot(b[0] - a[0], b[1] - a[1]);
        novo.push([(a[0] + b[0]) / 2 + rnd(-.5, .5) * d * .35, (a[1] + b[1]) / 2 + rnd(-.5, .5) * d * .35], b);
      }

    }

const camera = (() => {
  let video = null, stream = null, estadoCam = 'parado', erro = '', t0 = 0, usandoTras = true;
  function criarVideo() {
    if (video) return;
    video = document.createElement('video');
    video.setAttribute('playsinline', ''); video.muted = true; video.autoplay = true;
    video.style.cssText = 'position:fixed;width:1px;height:1px;opacity:0;pointer-events:none;left:-10px;top:-10px;';
    document.body.appendChild(video);
  }
  async function abrir() {
    criarVideo();
    estadoCam = 'abrindo'; erro = '';
    try {
      stream = await navigator.mediaDevices.getUserMedia({ video: { facingMode: usandoTras ? { ideal: 'environment' } : 'user' }, audio: false });
      video.srcObject = stream; await video.play().catch(() => {});
      estadoCam = 'ligado';
    } catch (e) {
      estadoCam = 'erro';
      erro = e.name === 'NotAllowedError' ? 'permita o uso da câmera' : e.name === 'NotFoundError' ? 'nenhuma câmera encontrada' : 'câmera indisponível';
    }
  }
  function fechar() {
    if (stream) { stream.getTracks().forEach(t => t.stop()); stream = null; }
    if (video) video.srcObject = null;
    estadoCam = 'parado';
  }
  return {
    alternarCamera() { usandoTras = !usandoTras; if (estadoCam === 'ligado' || estadoCam === 'abrindo') { fechar(); abrir(); } },
    entrar() { t0 = tempo; abrir(); },
    sair() { fechar(); },
    redim() {},
    desenhar(dt) {
      const t = tempo, n = P.nivel, S = Math.min(L, A);
      g.fillStyle = '#04070e'; g.fillRect(0, 0, L, A);
      // imagem da câmera (cobre a tela)
      if (estadoCam === 'ligado' && video && video.videoWidth) {
        const vw = video.videoWidth, vh = video.videoHeight;
        const escala = Math.max(L / vw, A / vh), dw = vw * escala, dh = vh * escala;
        g.save();
        if (!usandoTras) { g.translate(L, 0); g.scale(-1, 1); } // espelha a câmera frontal
        g.globalAlpha = 1; g.drawImage(video, (L - dw) / 2, (A - dh) / 2, dw, dh);
        g.restore();
        // leve tom ciano por cima
        g.fillStyle = `rgba(20,60,90,${.18 + .12 * Math.sin(t * .5)})`; g.fillRect(0, 0, L, A);
      }
      const CX = L / 2, CY = A * .45;
      g.globalCompositeOperation = 'lighter';
      // linha de varredura descendo

  const dt = Math.min(.05, (agora - ultimo) / 1000); ultimo = agora;

}

// Service worker do J.A.R.V.I.S. — deixa o app abrir rápido no celular,
// mesmo enquanto o servidor da nuvem acorda. NUNCA guarda respostas de /api.
const CACHE = 'jarvis-v7';
const SHELL = [
  './', 'cerebro.html', 'visuais.js', 'casa.html',
  'icone-192.png', 'icone-512.png', 'icone-maskable.png', 'apple-touch-icon.png',
  'manifest.webmanifest'
];

self.addEventListener('install', e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(SHELL)).then(() => self.skipWaiting()).catch(() => {}));
});

self.addEventListener('activate', e => {
  e.waitUntil(caches.keys().then(ks => Promise.all(ks.filter(k => k !== CACHE).map(k => caches.delete(k)))).then(() => self.clients.claim()));
});

self.addEventListener('fetch', e => {
  const req = e.request;
  if (req.method !== 'GET') return;
  const url = new URL(req.url);
  // dados ao vivo e outras origens: sempre pela rede, sem cache
  if (url.origin !== location.origin || url.pathname.includes('/api/')) return;
  // app: responde do cache e atualiza por trás (stale-while-revalidate)
  e.respondWith(
    caches.open(CACHE).then(async cache => {
      const cacheado = await cache.match(req, { ignoreSearch: true });
      const rede = fetch(req).then(resp => {
        if (resp && resp.status === 200 && resp.type === 'basic') cache.put(req, resp.clone());
        return resp;
      }).catch(() => cacheado);
      return cacheado || rede;
    })
  );
});
